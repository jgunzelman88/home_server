Local admin (always available as a fallback):
Username: root
Password: GitLab's auto-generated initial password. Read it with:
  kubectl -n {{ .Release.Namespace }} exec deploy/{{ include "gitlab.fullname" . }} -- grep 'Password:' /etc/gitlab/initial_root_password

  GitLab deletes that file 24 hours after the first reconfigure - log in and
  change the root password before then. If you miss it:
  kubectl -n {{ .Release.Namespace }} exec -it deploy/{{ include "gitlab.fullname" . }} -- gitlab-rake "gitlab:password:reset[root]"
